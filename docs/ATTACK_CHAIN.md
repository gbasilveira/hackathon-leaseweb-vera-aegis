# Synthetic incident narrative

The scenario begins with an already-compromised lab identity and an existing console session. Step through observations to see which tenant owns each resource. Read the same journal in the browser or evidence export. The scoped inventory, workload state changes and rejected access attempts are computed against local SQLite records. Each simulated operation checks the session and identity.

The initial investigation compares host-wide intervention with targeted identity containment. After suspension, the verifier checks actual grants through the original session and records whether requests were refused. To see the same access control apply in the attack timeline, pause playback after the initial evidence, contain the identity and resume the remaining fixture operations. On a second evaluation the operator can inject the new critical dependency, then demonstrate the gateway's refusal to consume a stale grant.
